bolt 基础流程
  1. 右侧「项目模板管理」中选择模板；管理员上传后所有成员/设备均可见（模板已服务端共享）
  2. 下方「文件导入」上传 CSV，可一次导入多份；每份 CSV 可分别选择对应项目
  3. 点击「结果导出」，进度条完成后即可查看结果
  4. 「预览结果」查看 Sheet3，「下载 XLSX」保存本地（保留模板格式与其它 Sheet）
preview 结果预览
  • 单项目多份 → 顶部下拉切换；多项目 → 自动按项目分栏并排
  • 数据居中显示 2 位小数，表头列宽可拖动；点击 QEPM 采样通道 单元格可看该通道的功率波形
  • 「数据组选择」面板可自由勾选哪些数据进入预览、加入哪个对比组
compare_arrows 结果对比
  • 右上「新建对比组」可建多个方案，同一份数据可加入多个组
  • 同项目对比 → 自动对齐公共列 + N/O/P 数值列，支持「高亮差异」
  • 跨项目对比 → 并排展示各项目表格，可按项目分别自定义公共列
  • 公共列自定义：填 A-D,M 之类列范围；或点「仅默认列（QEPM+Vavg）」「全部公共列」
show_chart 波形分析
  • CSV 原始数据预览下方勾选列可生成折线 / 柱状图；滚轮缩放、拖动平移、双击复位
  • 同项目对比 → 点击 QEPM 单元格自动叠加同名通道功率波形
  • 跨项目对比 → 每个项目分别点选一个通道，再点「生成对比曲线」叠加显示；数据缺失时会明确提示
admin_panel_settings 其它
  • 「历史操作记录」缓存在本机浏览器，可回溯或手动清空
  • 右上「管理员模式」可上传 / 替换 / 删除 / 重命名项目模板，操作对所有成员生效
