# 功耗续航工作台

支持 Supabase 邮箱账号登录、GitHub OAuth 管理员登录、云端模板和账号隔离历史记录的 PWA 功耗分析工具。未登录用户可使用游客模式和内置模板，但不会读取团队模板或云端历史。

## 功能模块

- **器件功耗数据库**：按一级 / 二级分类维护器件功耗数据，管理员可维护分类目录并上传 `.xlsx` / `.csv` 预览；分类结构与数据保存在浏览器 `localStorage`，不依赖 Supabase。
- **功耗拆解分析**：统一入口，进入后以二级列表展示三个子功能——
  - 项目模板管理：模板库管理，支持在线编辑「采样通道梳理」并生成拆解模板；
    - 采样通道梳理：本地 Excel / CSV 文档导入（自动识别表头并映射 15 个通道字段）、在线填写、通道列表预览与优先级统计（必测 / 合并 / 可选 / 不测 / 未标注）——统计标签为可点击的筛选按钮，点击后只展示对应类型的通道（保留原始行号），再次点击该标签或点「通道总数」恢复全部，筛选仅影响预览，不改变生成数据；云文档链接已停止在线取数，点「导入」统一提示「暂不支持云文档链接，请下载到本地后用本地文档的形式上传」；
    - 拆解模板自动生成：基于梳理结果，在前端生成 `项目名_功耗拆解数据处理模板_日期.xlsx`（8 个 Sheet，结构对齐 `DoraG_功耗拆解数据处理模板V1.0.xlsx`），无需后端；生成时写入可重算的公式：`3_功耗采集数据表` 的 Vavg/Iavg/Pavg（按 QEPM 通道名 HLOOKUP 取实测均值）、DCDC/LDO 效率（VLOOKUP 回 `2_电源信息表`）、Total Efficiency、Power @VBATT mW、Power in Sum(mW)，`2_电源信息表` 的 SMPS 电流合计与按负载点插值的效率，`4-统计` 的模块/子模块 SUMIFS 与合计行，`5-测试原始数据` 的 AVERAGE 均值行；
    - 导出格式还原：SheetJS 社区版（`xlsx@0.18.5`）写不出单元格样式，因此「生成拆解模板」改用 **ExcelJS** 落盘——按 `DoraG_功耗拆解数据处理模板V1.0.xlsx` 还原每个 Sheet 的合并单元格（含 `1_电源配置表` / `3_功耗采集数据表` 的模块、子模块、tiny模块纵向合并）、表头配色（`1` 表浅蓝、`3` 表灰、`2` 表灰/红/黄/绿、`4` 表浅蓝+浅绿）、数据区按列语义配色与优先级条件色、列宽、行高，以及 `1_电源配置表`（E3）与 `3_功耗采集数据表`（N4）的冻结窗格；ExcelJS 未加载时自动降级为纯值+公式导出；
    - 合并单元格语义：原模板「模块 / 子模块 / tiny模块」是纵向合并（仅块首行有值），导入时会向下填充，保证 `4-统计` 的 SUMIFS 不漏通道；
    - `2_电源信息表` 固定数据：SMPS / LDO 两个子表的 PMIC、Voltage、V_In（DCDC）、V_In、V_Out 直接复制自原模板（模板里 PMIC 是跨行合并，已展开到每一行），效率占位仍为 0.8，按实测替换；项目 rail 名（如 `VREG_S9A_0P728V`）会与模板短名（`S9A`）对齐后带出静态信息，模板剩余行按原顺序补在后面；
    - 对齐与合并：所有 sheet 单元格统一水平居中 + 垂直居中；`4-统计` 子模块明细的「模块」列按连续同名纵向合并（公式引用块首单元格 `$A$块首行`）；`3_功耗采集数据表` 的 A/B 列**不做**合并，否则 `4-统计` 的 SUMIFS/COUNTIFS 会因非块首行空白而漏统计；
    - 配置文件生成：把「采样通道梳理」的 `采样通道QC` 列（`SPM1_CH07` / `SPM2_CH42`，`采样通道NI` 列不参与）翻译成 SPMv4 采样配置 `.conf`——按 `channel = 32 × (nn % 4) + 2 × ⌊nn / 4⌋` 计算槽位（I 占 `channel`、V 占 `channel + 1`），电流通道取「采样电阻」、电压通道固定 `1000`，类别按「模块」两位编码映射为 `00_VBATT ~ 10_OTHERS`，空槽补 `disabled: 1` 占位，并在每个芯片末尾追加 `SPM_SENSE48 ~ 63` 测试通道与 3 个 marker（共 131 条 / 芯片）；数据源与上方「采样通道梳理」完全共用同一份通道数据（本地文档导入 / 在线填写），本区块不再提供独立的云文档链接输入与读取按钮，仅保留共用数据源的提示；云文档链接暂不支持在线取数（在上方「采样通道梳理 → 云文档导入」点「导入」会提示「暂不支持云文档链接，请下载到本地后用本地文档的形式上传」）；结果区给出有效通道 / 空槽 / 跳过统计、跳过原因、逐文件预览、复制、单文件下载与打包下载；**DAB 固定为全小写 `spmv4`**：输入框只读、带「固定值」标识且不参与必填校验，生成、保存与缓存恢复统一使用常量，旧缓存里的其他写法会被强制覆盖；生成前「项目名称 / 平台 Target」两项与「采集卡位号映射」必填（默认留空，仅在 placeholder 里给示例），任一为空即拦下并高亮提示，不产出文件；卡位号按通道数据里实际识别到的 SPM 芯片（SPM1 / SPM2 / SPM3…）动态渲染独立输入框，与芯片一一对应，文件名 `{项目名称}_{SPM}_{卡位号}.conf` 严格取该芯片自己的卡位号、不再自动递增；手填的值写入 localStorage（新结构 `serials` 按芯片存储），刷新后可复现；旧版本单个「起始卡位号」缓存会在首次渲染时按芯片顺序自动递增迁移，新结构一旦保存迁移即失效、新出现的芯片留空待显式填写。
  - 拆解数据对比分析：导入 CSV / Excel，生成结果并完成多项目对比；
  - 拆解数据导出：选择模板、导入数据并按需导出 Excel 或云文档。
- **续航/功耗预估**：开发中占位模块。
- **续航/功耗现状**（纯前端、localStorage 持久化，游客模式可用，key `endurance_status_v1`；数据模型已升级到 v2，旧 v1 数据打开时自动迁移）：
  - 项目管理：新增 / 重命名 / 删除多个项目，删除项目会级联清理其电池参数、场景台账与模型；全部删除后展示空态引导；
  - 电池参数：电池容量 mAh（Typ）、电池容量 Min（mAh）、额定容量 Wh、额定电压 V、**关机电压 V**、**可放电容量比例(0.2C)**、低电量门限；比例与门限校验 0~1，所有参数拒绝非数字与负数，非法输入红框提示且不写入，实时保存；
  - 电池可放电容量查询表：维护「电压 → 累计可放出容量 mAh」点列（按电压降序、同电压去重），支持 `.xlsx` / `.xls` / `.csv` 导入，自动识别直接可放电 mAh、剩余 mAh、可放电比例、剩余 SOC 四类表头（剩余口径需填写 Typ 容量换算）；关机电压对应的可放电容量按线性插值计算并自动回填比例，比例超过 100% 时判定数据异常、不回填；查询表容量即规格书 0.2C 放电曲线口径，不做 OCR / PDF / Word 识别；
  - 场景电流（原「场景电流台账」）：按场景维护功耗标准 / 门限、当前电流（自定义电流优先，为空时取最新测试记录）、测试版本、更新日期、备注 / 说明，支持新增自定义列；测试记录按「日期 + 版本 + 电流」留痕并可查看历史，日期校验 `YYYY-MM-DD`，删除场景会同步清理模型中的引用行；
  - 公式驱动续航模型（v2）：每个项目可保存多个模型，支持新建 / 复制（列 ID、行 ID、foot 映射全部重生成）/ 切换 / 重命名 / 删除；模型为「对比列 × 场景行」网格，支持新增对比列（普通 / 满电两种口径）、新增场景行（可关联已有场景或新建场景）、删除列（至少保留一列）；
  - 安全公式引擎（`formula.js`）：自研词法 / 语法分析 + 递归下降求值，**不使用 eval / new Function**；支持数字、四则、幂、括号、一元正负、比较运算（`> < >= <= = <>`）、A1 引用（`B2` / `$B$2` / `B$2` / `$B2`）与区间（仅限聚合参数）、中英文命名参数，函数 `SUM / AVG / MIN / MAX / ABS / ROUND / IF / POWER / SQRT`（含中文别名，IF 惰性求值）；错误码 `#REF! / #DIV/0! / #CYCLE! / #NAME? / #VALUE! / #SYNTAX!`，模型层 memo 检测循环引用；
  - 默认模型对齐云表「续航模型」V1.0：内置 12 个场景与 UT3H / 常开 / 重度三个对比列；场景耗电默认 `=IF(时长=0,0,电流*时长)`（0 时长自动得 0，缺电流不污染汇总），Total 为 `SUM`，普通列可使用时长 `=可用容量/总耗电*总时长`、满电列 `=Typ/总耗电*总时长`；其中**可用容量 = Typ × 可放电容量比例(0.2C)**，云表中的 239 不硬编码，随电池参数实时联动；所有单元格（含时长、耗电、Total、DOU）均可通过 fx 弹层编辑公式，弹层支持实时试算、快捷插入、恢复默认与语法拦截，语义错误可保存并在格内标红；
  - 多项目横向对比：场景电流柱状图与 DOU 柱状图（Chart.js），对比项目与对比场景均为多选 chip、首次默认全量；场景池按全部项目的场景名取并集，跨项目同名场景同组对比；用户清空 / 取消的选择在整页重渲染后保持（仅真正新增的项目 / 场景自动纳入），场景 chip 始终渲染全部可选项；图表实例同 canvas 重绘前先销毁、静默刷新与整页渲染统一回收，重绘无泄漏；
  - 数据边界：续航数据仅保存在当前浏览器 localStorage，**不做云端同步，不支持多设备共享**；更换浏览器 / 清理站点数据会丢失，可通过浏览器本地备份（后续可基于现有 Supabase 基础设施扩展管理员写入、多设备只读同步）。

## Supabase 初始化

1. 在目标 Supabase 项目的 SQL Editor 执行 `supabase-schema.sql`。
2. 在 Authentication → URL Configuration 中加入生产地址（例如 `https://power-analysis-alpha.vercel.app`）。
3. 在 Authentication → Sign In / Providers → GitHub 中填入 GitHub OAuth App 的 Client ID / Client Secret，并启用 GitHub 登录。
4. 在 `config.js` 的 `adminEmails` / `adminGithubLogins` 中维护管理员邮箱和 GitHub 用户名白名单，并同步修改 SQL 中的管理员策略。

## 云文档导入（飞书电子表格）——已下线

> **当前状态：** 前端已下线云文档在线取数。点击「采样通道梳理 → 云文档导入」的「导入」按钮只会提示
> 「暂不支持云文档链接，请下载到本地后用本地文档的形式上传」，**不会发起任何网络请求**。
> 请用飞书「··· → 下载 → Excel」导出后，通过「本地文档导入」完成导入。
> 下面保留原代理方案说明，仅作为历史 / 可选后端能力参考，前端已不再调用。

「云文档导入」通过 Supabase Edge Function `feishu-sheet-proxy` 代理取数：浏览器只传飞书表格链接，
函数在服务端用飞书应用凭证换取 `tenant_access_token` 后读取表格，返回二维数组给前端复用本地导入的解析逻辑。
前端不会也不应该保存飞书 App Secret。

### 1. 在飞书开放平台准备应用

1. 创建自建应用，获取 **App ID** / **App Secret**。
2. 开通权限：`sheets:spreadsheet:readonly`（读取电子表格）、`sheets:spreadsheet`（读取工作表列表，如接口要求）。
3. 发布应用版本，并把该应用（机器人）添加为目标文档的**协作者（可阅读）**——云文档只能读取应用被授权的文档。

### 2. 配置并部署 Edge Function

```bash
supabase login
supabase link --project-ref osopccfscvxcukspwkzv

# 注入飞书应用凭证（不要写进仓库或前端代码）
supabase secrets set FEISHU_APP_ID=<app_id> FEISHU_APP_SECRET=<app_secret> \
  --project-ref osopccfscvxcukspwkzv

supabase functions deploy feishu-sheet-proxy --project-ref osopccfscvxcukspwkzv
```

可选环境变量：

| 变量 | 说明 |
| --- | --- |
| `LARK_API_BASE` | 默认 `https://open.feishu.cn/open-apis`；Lark 国际版改为 `https://open.larksuite.com/open-apis` |
| `FEISHU_PROXY_TOKEN` | 设置后前端须在 `config.js` 的 `feishuSheetProxyToken` 填入同一口令，请求头 `x-proxy-token` 校验 |

`supabase/config.toml` 中该函数已声明 `verify_jwt = false`（游客模式也能导入），因此它只提供**只读**接口，
且读取范围受限于飞书应用的文档授权。

### 3. 前端配置

`config.js`：

```js
feishuSheetProxyEndpoint: 'https://<project-ref>.supabase.co/functions/v1/feishu-sheet-proxy',
feishuSheetProxyToken: '', // 仅在 Edge Function 配置了 FEISHU_PROXY_TOKEN 时填写
```

### 4. 使用方式与降级方案

粘贴形如 `https://xxx.larkoffice.com/sheets/XXXXXXXX?sheet=xxxxxx` 的电子表格链接后点「导入」：
自动选中链接里 `sheet=` 指定的工作表（未指定时取第一个可见工作表），也可在「选择工作表」中切换后重读。
已有数据时会询问「覆盖 / 追加」。

若代理未部署或未授权（状态栏会给出具体原因），可在飞书中「··· → 下载 → Excel」导出后用「本地文档导入」完成导入。

健康检查：`GET <feishuSheetProxyEndpoint>` 返回 `{ ok, configured }`，`configured=false` 表示凭证未配置。
